# Frontend

This folder contains the current React frontend prototype for Review Sense.

## Current Role

- text input and batch review UI
- visualization prototype
- temporary Gemini-based demo flow

## Planned Role

The frontend will be redesigned into a stronger AI-product style experience and connected to the FastAPI backend instead of calling Gemini directly from the browser.

## Next Frontend Tasks

- replace direct Gemini usage with backend API calls
- redesign the interface
- add confidence and top-emotion views
- support future fake/spam review mode
